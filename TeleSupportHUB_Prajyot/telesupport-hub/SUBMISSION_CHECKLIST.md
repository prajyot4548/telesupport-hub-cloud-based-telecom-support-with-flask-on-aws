# Submission Checklist

Use this before 2 PM.

## Install and Run

1. Open PowerShell.
2. Run:

```powershell
cd "D:\Downloads\make new folder here\telesupport-hub"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

3. Open `http://127.0.0.1:5000`.

## GitHub Upload

1. Create a public GitHub repository named `telesupport-hub`.
2. Upload these files/folders:
   - `app.py`
   - `requirements.txt`
   - `schema.sql`
   - `templates/`
   - `static/`
   - `README.md`
   - `PROJECT_DOCUMENTATION.md`
3. Copy the GitHub repository link.
4. Paste it in SmartInternz `Git Repo`.

## Project Doc

Upload or paste `PROJECT_DOCUMENTATION.md` content in the `Project Doc` deliverable.

## Demo Link

Fastest option:

1. Record a 2-3 minute screen video.
2. Show home, login, buy service, raise ticket, agent dashboard, and database preview.
3. Upload to Google Drive.
4. Set sharing to anyone with the link.
5. Paste the link in `Demo Link`.
